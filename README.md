# Site YB Digiora (version à plat)
Tous les fichiers sont au même niveau.
- Textes, tarifs, FAQ : index.html
- Numéro WhatsApp, lien Facebook, liste des captures : début de main.js
- Ajouter une capture : envoyer l'image dans le dépôt, puis ajouter une ligne dans PROOFS (main.js) avec le nom du fichier.
- Remplacer VOTRE-DOMAINE dans robots.txt et sitemap.xml après publication.
